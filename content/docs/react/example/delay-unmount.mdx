如果只使用 `open`，关闭时会有一个问题：

```jsx
{open && (
  <div className="animate-close">
    ...
  </div>
)}
```

如果open === false，div将直接从DOM中删除

结果：

- ❌ 关闭动画还没开始，元素已经不存在了

- ❌ CSS animation 没机会播放

所以这里拆成两个状态：

```jsx
const { open } = useAISearchContext();
const [actualOpen, setActualOpen] = useState(open);
```

| 状态         | 作用                          |
| ------------ | ----------------------------- |
| `open`       | 业务状态：用户想不想打开      |
| `actualOpen` | DOM状态：组件是否还存在于页面 |

初始：

```jsx
open = false
actualOpen = false
```

用户点击打开：

```jsx
open = true
actualOpen = false
```

执行：

```jsx
if (open && !actualOpen) 
  setActualOpen(open);
```

```jsx
open = true
actualOpen = true
```

用户关闭：

```jsx
open = false
actualOpen = true
```

DOM仍然存在，当DOM动画结束：

```jsx
onAnimationEnd={() => {
  if (!open) {
    flushSync(() => setActualOpen(false));
  }
}}
```

```jsx
open = false
actualOpen = false
```

最后 DOM 被延迟删除。

调用 `setState` 后,React 不会立刻重新渲染,而是调度到稍后统一提交:

```jsx
function handleClick() {
  setCount(c => c + 1);
  console.log(ref.current.textContent); // ❌ 还是旧值,DOM 尚未更新
}
```

强制 React 同步处理状态更新：

```jsx
import { flushSync } from 'react-dom';

flushSync(() => {
  setSomething(123);
});
// 执行到这里时,DOM 已经更新完毕 ✅
```
