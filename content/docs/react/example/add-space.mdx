## 引入问题

浏览器会去掉 JSX 标签之间用于格式化代码的空白。不会去掉**同一个文本节点内部的空白**

```jsx
<div>
  or the
  <a href="#">link</a>
</div>
```

这里 浏览器 看到的是两个部分：

一个文本节点：

or 和 the 在同一个文本节点里，所以中间的空格属于文本内容，会被保留。

```jsx
 "or the"
```

一个元素节点：

```jsx
<a>link</a>
```



## 添加空格

```jsx
<div>
  or the{' '}
  <a href="#">link</a>
</div>
```
