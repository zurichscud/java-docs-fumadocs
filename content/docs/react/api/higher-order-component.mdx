---
title: "高阶组件"
---

**高阶组件（Higher-Order Component，简称 HOC）**是 React 中用于**复用组件逻辑**的一种高级模式。



## 基本语法

```jsx
// HOC 的基本结构
function withExtraProps(WrappedComponent) {
  return function EnhancedComponent(props) {
    // 1. 执行逻辑/获取额外数据
    const extraInfo = "额外的信息";
    
    // 2. 将透传 props 与新属性组合后传递给原组件
    return <WrappedComponent extraInfo={extraInfo} {...props} />;
  };
}
```
