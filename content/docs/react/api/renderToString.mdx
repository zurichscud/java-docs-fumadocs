---
title: "renderToString"
descirption: "将 React 树渲染为一个 HTML 字符串"
---

## Usage

```jsx
const html = renderToString(reactNode, options?)
```

在服务器，调用 `renderToString` 将你的应用渲染为 HTML。

- `reactNode`：你要渲染为 HTML 的 React 节点。例如，一个 JSX 节点，就像 `<App />`。

- `options`：可选，服务器渲染的对象。



## Example

```js
import { renderToString } from 'react-dom/server';

// 路由处理程序的语法取决于你使用的后端框架
app.use('/', (request, response) => {
  const html = renderToString(<App />);
  response.send(html);
});
```

这将生成你的 React 组件的初始非交互式 HTML 输出。在客户端上，你需要调用 [`hydrateRoot`](https://zh-hans.react.dev/reference/react-dom/client/hydrateRoot) 来将服务器生成的 HTML 进行激活处理，使其具有交互功能。
