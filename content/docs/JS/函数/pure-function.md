## 纯函数定义

如果一个函数满足以下两个条件，它就是纯函数：

1. **确定的输入产生确定的输出**：对于相同的输入参数，无论调用多少次、在什么环境下执行，函数返回的结果永远相同（即“可预测性”）。

2. **无副作用（No Side Effects）**：函数在执行过程中，不会修改外部状态，也不会产生任何可被外界察觉的副作用。

## 纯函数示例

```js
function add(a, b) {
  return a + b;
}

add(1, 2); // 永远返回 3
add(1, 2); // 永远返回 3
```

这个函数是纯函数。因为结果只由 `a` 和 `b` 决定。

```js
n=>n+1
```

相同的输入具有相同的输出，函数没有更改n的值，只是将n+1返回了，因此是纯函数

## 非纯函数示例

```js
let count = 10;

function add(num) {
  return num + count;
}

add(5); // 15
```

函数依赖于外部count的状态，如果count更改为20，对于相同的输入num，输出不同，因此不是纯函数
