---
title: "高阶函数"

descirption: 操作函数的函数 
---

高级函数接收一个或多个函数作为参数，或者返回一个函数的函数。

## 函数作为参数

例如：

```jsx
function sayHello(name) {
  console.log(`Hello ${name}`);
}

function execute(fn, value) {
  fn(value);
}

execute(sayHello, 'Tom');
```



## 函数作为返回值

```jsx
function createMultiplier(x) {
  return function (y) {
    return x * y;
  };
}

const double = createMultiplier(2);

console.log(double(5));
```



## 高阶函数的意义

### 代码复用

```jsx
function withLog(fn){
  return function(){
    console.log('执行前');
    fn();
    console.log('执行后');
  }
}
```

给任何函数增加日志功能。

### 函数增强

```jsx
const newFn = withLog(oldFn);
```

不用修改 `oldFn`，直接增强它。
