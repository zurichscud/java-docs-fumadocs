---
title: "dotenv"
---

`dotenv` 是一个用于**读取 `.env` 环境变量文件**的 Node.js 包。它的作用是把 `.env` 文件里的配置加载到 `process.env` 中。

## install

```sh
npm install dotenv
```

## Usage

创建 `.env`：

```
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=123456

JWT_SECRET=abc123
```

读取环境变量：

```js
import dotenv from "dotenv";

dotenv.config();

console.log(process.env.DB_HOST);
```

指定 env 文件：

```js
dotenv.config({
  path: ".env.development",
});
```

配合`cross-env`一起使用：

```js
dotenv.config({
  path:
    process.env.NODE_ENV === "production"
      ? ".env.production"
      : ".env.development",
});
```
