---
title: "请求头语法"
---

| 分隔符   | 作用                       | 语义                      |
| -------- | -------------------------- | ------------------------- |
| 逗号 `,` | 分隔**多个独立的值**(列表) | “我要 A、B、C 中任意一个” |
| 分号 `;` | 分隔**某个值的参数/属性**  | 附属于紧邻前面的那个值    |

```
值1;参数1;参数2,
值2;参数1;参数2,
值3;参数1;参数2
```

```
Accept-Language: zh-CN,zh;q=0.9,en;q=0.8
```

实际上表达的是：

```
[
  { value: "zh-CN" },
  { value: "zh", q: 0.9 },
  { value: "en", q: 0.8 }
]
```
