---
title: "notFound"
descirption: "用于处理 404 资源不存在 的函数"
---

`notFound` 函数会抛出一个错误，并渲染一个 Next.js 404 页面。它对于处理应用程序中缺失的资源非常有用。您可以使用 `not-found.js` 文件自定义 UI。

## Usage

调用 `notFound()` 会抛出 `NEXT_HTTP_ERROR_FALLBACK;404` 错误，并终止抛出该错误所在路由段的渲染。

`notFound() `可以在服务器组件、服务器函数和路由处理程序中调用。

```jsx title="app/user/[id]/page.tsx"
import { notFound } from 'next/navigation'
 
async function fetchUser(id: string) {
  const res = await fetch('https://...')
  if (!res.ok) return undefined
  return res.json()
}
 
export default async function Profile({
  params,
}: {
  params: Promise<{ id: string }>
}) {
  const { id } = await params
  const user = await fetchUser(id)
 
  if (!user) {
    notFound()
  }
 
  // ...
}
```

## 路由段级别匹配

Next.js 会寻找**最近的 not-found 文件**。

```
app/
 ├── not-found.tsx
 └── dashboard/
      ├── not-found.tsx
      └── users/
           └── [id]/
                └── page.tsx
```

- notFound将会使用`dashboard/users/[id]/not-found.tsx`这个文件

- 根级 `app/not-found.tsx`可以处理整个应用

- NextJS内置了默认的`not-found.tsx`作为兜底
