## Set up

配置Prisma Client

### Prerequisites

In order to set up Prisma Client, you need a [Prisma schema file](https://docs.prisma.io/docs/orm/v6/prisma-schema/overview) with your database connection, the Prisma Client generator, and at least one model:

```prisma title="schema.prisma"
datasource db {
  provider = "postgresql"
}

generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
}

model User {
  id        Int      @id @default(autoincrement())
  createdAt DateTime @default(now())
  email     String   @unique
  name      String?
}
```

 install the Prisma CLI:

```sh
pnpm add prisma --save-dev
```

### Install

Install Prisma Client in your project with the following command:

```sh
pnpm add @prisma/client
```

### Import Prisma Client

```sh
import { PrismaClient } from "./generated/prisma";

const prisma = new PrismaClient();
// use `prisma` in your application to read and write data in your DB
```

### Use

```js
// run inside `async` function
const newUser = await prisma.user.create({
  data: {
    name: "Alice",
    email: "alice@prisma.io",
  },
});

const users = await prisma.user.findMany();
```

<Callout title="注意" >

所有Prisma Client 的方法返回 Promise 类型

</Callout>

### Update Prisma Client

当你的数据库结构发生变化，并且这些变化同步到了 Prisma schema 文件后，你需要手动重新生成 Prisma Client，这样生成出来的代码才能反映最新的数据库结构。
