title: "Image"

`next/image` 是 Next.js 内置的图片组件,它对原生 `<img>` 标签做了大量优化,是提升网页性能的重要工具。

## 为什么用它

相比直接用 `<img>`,它自动解决了几个问题:

1. 自动格式转换 — 根据浏览器支持,将图片转为 WebP / AVIF,体积更小
2. 自动响应式尺寸 — 生成多个尺寸的图片(`srcset`),手机不会加载桌面级大图
3. 懒加载 — 默认 `loading="lazy"`,视口外的图片不加载
4. 防止布局偏移(CLS) — 强制你声明宽高,避免图片加载时页面跳动
5. 按需缩放 — 服务端按请求的实际需要缩放图片,原图多大都没关系

## 基本用法

### 本地图片

根路径为`public`目录

```jsx
import Image from "next/image"
export default function Home() {
    return (
        <div>
            <h1>Home</h1>
            <Image
                src="/1.png"
                width={100}
                height={100}
                alt="1"
            />
        </div>
    )
}
```

### 静态图片

使用`import`引入图片，是不需要填写宽度和高度，Next.js会自动确定图片的尺寸。

```jsx
import Image from 'next/image';
import profilePic from '@/public/me.png';

export default function Avatar() {
  return (
    <Image
      src={profilePic}
      alt="头像"
      placeholder="blur" // 自动获得模糊占位图
    />
  );
}
```

### 远程图片

例如OSS中的图片

```jsx
<Image
  src="https://example.com/photo.jpg"
  alt="描述"
  width={800}
  height={600}
/>
```

远程图片必须先在配置里白名单:

```js
// next.config.js
module.exports = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'example.com',
        pathname: '/**',
      },
    ],
  },
};
```
