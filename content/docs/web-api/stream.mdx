title: "ReadableStream"
---

`ReadableStream` 是 Web API（Streams API）中用于处理可读数据流的核心接口。它允许你按块（chunk）异步地读取数据，而不是一次性将所有数据全部加载到内存中。这对于处理**超大文件、实时视频/音频流、网络请求**等场景至关重要。

## 核心工作原理

- **Underlying Source（底层源）**：数据的真正来源（如网络 Socket、文件系统、本地生成的算法数据）。

- **Controller（控制器）**：用于向流中压入数据（`enqueue`）、抛出错误（`error`）或关闭流（`close`）。

- **Reader（读取器）**：流的唯一访问入口。一旦流被锁定（locked）给某个 Reader，其他代码就无法同时读取。

## 创建ReadableStream

你可以通过构造函数传入 `start`、`pull`、`cancel` 等钩子函数来自定义一个数据流：

```js
const customStream = new ReadableStream({
  start(controller) {
    // 流初始化时触发，可以压入初始数据
    controller.enqueue("Hello");
    controller.enqueue(" World!");
    controller.close(); // 标记数据发送完毕
  },
  pull(controller) {
    // 当内部缓冲区未满且 Reader 请求更多数据时触发
  },
  cancel(reason) {
    // 当 Reader 显式取消流时触发
  },
});
```

## 读取 ReadableStream

使用 `getReader()` 锁住流，并通过 `read()` 循环获取数据块：

```js
const reader = customStream.getReader();

async function readStream() {
  while (true) {
    // read() 返回 { value: Chunk, done: boolean }
    const { value, done } = await reader.read();

    if (done) {
      console.log("流已完全读取完毕");
      break;
    }

    console.log("读取到的数据块:", value);
  }
}

readStream();
```

<Accordions type="single">
  <Accordion title="为什么需要 Reader？">
    在 Streams API 中，流是可共享的资源。为了确保数据的一致性和避免竞争条件，流在被读取时会被锁定给一个 Reader。这样可以保证同一时间只有一个读取器在处理流的数据，避免了多线程/多任务环境下的数据冲突问题。
    
Java 当时为什么不这样设计：1996 年采用的是“同步阻塞 + 显式 Buffer 传参”范式，简单直观，在当时的单线程/多线程模型下完全够用。

## 使用 `for await...of` 简化读取

在较新的浏览器和 Node.js 环境中，`ReadableStream` 实现了异步迭代协议，读取变得非常优雅：

```js
for await (const chunk of stream) {
  console.log("Chunk:", chunk);
}
```

## Example

处理 Fetch 流式响应

```js
async function fetchStreamText() {
  const response = await fetch("https://api.example.com/stream");

  // response.body 即是一个 ReadableStream<Uint8Array>
  const reader = response.body.getReader();
  const decoder = new TextDecoder("utf-8"); // 用于将 Uint8Array 转为字符串

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    // 解码并实时打印/渲染到界面上
    const textChunk = decoder.decode(value, { stream: true });
    console.log("收到新片段:", textChunk);
  }
}
```
