---
title: "FileInputStream"
---

`FileInputStream` 是 **字节输入流**，用于把数据从 文件读取到JVM 内存。

## Usage

## Constructor

### 根据字符串路径

```java
FileInputStream in = new FileInputStream("test.txt");
```

### 根据 File 对象

```java
File file = new File("test.txt");
FileInputStream in = new FileInputStream(file);
```

- 文件不存在、是目录或无法读取时，都会抛出 `FileNotFoundException`

> 还提供了 `FileInputStream(FileDescriptor fdObj)`，通过底层文件描述符创建，日常开发很少使用。

## Methods

### read()

读取一个字节

```java
public int read() throws IOException
```

- Return：读取到的字节值（`0 ~ 255`）；到达文件末尾时返回 `-1`，读取失败抛出 `IOException`

```java
FileInputStream in = new FileInputStream("test.txt");

int data;

while ((data = in.read()) != -1) {
    System.out.println(data);
}

in.close();
```

### read(byte[] b)

读取到字节数组

```java
public int read(byte b[]) throws IOException
```

- b：用于存放读取数据的字节数组（缓冲区）
- Return：本次实际读取到的字节数；到达文件末尾（没有更多数据）时返回 `-1`

```java
FileInputStream in = new FileInputStream("test.txt");

byte[] buffer = new byte[3];

int len;

while ((len = in.read(buffer)) != -1) {
    System.out.println(new String(buffer, 0, len));
}

in.close();
```

**注意**：`read(b)` 不保证把数组填满，返回值可能**小于 `b.length`**。比如缓冲区长度为 `1024`，但文件只剩下 5 个字节，本次就只读取这 5 个字节并返回 `5`；下一次调用才返回 `-1`。所以不能拿 `b.length` 当作本次读取的有效长度，必须使用返回值 `len`。
