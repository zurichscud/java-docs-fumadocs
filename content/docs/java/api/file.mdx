---
title: "File"
---

`java.io.File` 是 Java 早期提供的**文件和目录路径抽象类**。

## Usage

`File` 的相对路径是相对于 **JVM 当前工作目录（Working Directory）** 的，而不是相对于当前 Java 文件所在目录。

## Constructor

### 根据字符串路径

```java
File file = new File("D:/test.txt");
```

### 父路径 + 子路径

```java
File file = new File("D:/", "test.txt");
```

### File + 子路径

```java
File parent = new File("D:/");
File file = new File(parent, "test.txt");
```

## Methods

> `File` 只是路径的抽象，本身**不负责读写文件内容**；读写内容需要使用字节流/字符流或 `java.nio.file.Files`。

> `File` 本质上只是一个**路径对象**，很多方法（getter）并不会访问磁盘验证文件是否存在。

### createNewFile()

创建当前路径对应的空文件。创建成功返回 `true`；文件已存在返回 `false`。父目录必须已存在，否则抛出 `IOException`。

```java
File file = new File("D:/test.txt");
boolean created = file.createNewFile();
```

### mkdir()

创建**单级目录**，成功返回 `true`。父目录不存在时会失败并返回 `false`。

```java
new File("D:/test").mkdir();
```

### mkdirs()

创建**多级目录**，不存在的父目录会自动创建，成功返回 `true`（实际开发中更常用）。

```java
new File("D:/test/a/b").mkdirs();
```

### delete()

删除文件或**空目录**，成功返回 `true`。非空目录无法删除（需要先递归删除内部文件），删除失败时不抛异常，只返回 `false`。

```java
boolean deleted = file.delete();
```

### exists()

判断文件或目录是否存在。

```java
if (file.exists()) {
    // ...
}
```

### isFile()

判断路径是否存在且为**文件**。

### isDirectory()

判断路径是否存在且为**目录**。

### length()

返回文件大小，单位为字节；文件不存在时返回 `0`，**对目录的返回值不确定**。

```java
long size = file.length();
```

### getName()

返回文件名，或路径最后一级的目录名。

```java
new File("D:/test/a.txt").getName(); // a.txt
```

### getParent()

返回父路径字符串；没有父路径时返回 `null`。

### getPath()

返回构造 `File` 时传入的原路径（可能是相对路径）。

### getAbsolutePath()

返回绝对路径，但**不解析** `.` 和 `..`。

### getCanonicalPath()

返回规范化后的绝对路径（解析 `.`、`..` 和符号链接），可能抛出 `IOException`。

```java
File file = new File("D:/test/../a.txt");
file.getAbsolutePath();  // D:\test\..\a.txt
file.getCanonicalPath(); // D:\a.txt
```

### list()

返回目录下所有文件/子目录的**名称数组**（`String[]`）；路径不存在或不是目录时返回 `null`。

### listFiles()

返回目录下所有文件/子目录的 `File` 数组；路径不存在或不是目录时返回 `null`。

```java
File[] files = new File("D:/test").listFiles();
for (File f : files) {
    System.out.println(f.getName());
}
```

### renameTo(File dest)

重命名或移动文件/目录，`dest` 需传完整的目标路径。跨分区移动、目标已存在等情况可能失败，失败时只返回 `false`，属于平台相关行为。新代码推荐使用 `Files.move()`。

```java
File src = new File("D:/test.txt");
File dest = new File("D:/test2.txt");
boolean renamed = src.renameTo(dest);
```
