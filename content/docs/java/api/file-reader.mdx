---
title: "FileReader"
---

`FileReader` 是**字符输入流**，继承自 [`Reader`](/docs/java/api/reader)，用于将文件中的**字符数据读取到程序**中（输入流），默认使用**操作系统默认编码**解码。

## Usage

通用读取方法（`read()`、`ready()`、`close()` 等）继承自 `Reader`；需要按行读取或减少磁盘 I/O 时，再用[包装流 `BufferedReader`](/docs/java/api/buffered-reader) 包装它。

```java
try (FileReader reader = new FileReader("test.txt")) {

    char[] buffer = new char[1024];

    int len;

    while ((len = reader.read(buffer)) != -1) {
        System.out.print(new String(buffer, 0, len));
    }

}
```

## Constructor

### FileReader(String fileName)

```java
FileReader reader = new FileReader("test.txt");
```

- 根据文件路径创建，使用**操作系统默认编码**
- 文件不存在、是目录或无法读取时，都会抛出 `FileNotFoundException`

### FileReader(File file)

```java
File file = new File("test.txt");
FileReader reader = new FileReader(file);
```

- 行为与 `FileReader(String fileName)` 一致

## Methods

> `FileReader` 特有的方法只有下面这个；其余方法继承自 `Reader`。

### getEncoding()

返回此流使用的字符编码名称（如 `UTF8`、`GBK`）。

```java
public String getEncoding()
```

```java
FileReader reader = new FileReader("test.txt");

System.out.println(reader.getEncoding()); // UTF8

reader.close();
```
