---
title: "FileWriter"
---

`FileWriter` 是**字符输出流**，继承自 [`Writer`](/docs/java/api/writer)，用于将程序中的**字符数据写入到文件**中（输出流），默认使用**平台默认字符集**编码。

> 通用写入方法（`write()`、`flush()`、`close()` 等）继承自 `Writer`；需要缓冲减少磁盘 I/O 时，再用[包装流 `BufferedWriter`](/docs/java/api/buffered-writer) 包装它。

## Usage

```java
try (FileWriter writer = new FileWriter("test.txt")) {

    writer.write("hello 你好");

}
```

## Constructor

### FileWriter(String fileName)

```java
FileWriter writer = new FileWriter("test.txt");
```

- 根据文件路径创建，使用**平台默认字符集**
- 文件不存在时会自动创建；已存在时**清空原内容**再写入
- 文件无法创建或打开时，都会抛出 `IOException`

### FileWriter(String fileName, boolean append)

```java
FileWriter writer = new FileWriter("test.txt", true);
```

- append：为 `true` 时数据追加到文件末尾，原内容保留；为 `false` 时等价于默认的覆盖模式

### FileWriter(File file)

```java
File file = new File("test.txt");
FileWriter writer = new FileWriter(file);
```

- 行为与 `FileWriter(String fileName)` 一致

### FileWriter(File file, boolean append)

```java
FileWriter writer = new FileWriter(file, true);
```

- 行为与 `FileWriter(String fileName, boolean append)` 一致

## Methods

> `FileWriter` 特有的方法只有下面这个；`write()`、`flush()`、`close()` 等其余方法继承自 `Writer`。

### getEncoding()

返回此流使用的字符编码名称（如 `UTF8`、`GBK`）。

```java
public String getEncoding()
```

```java
FileWriter writer = new FileWriter("test.txt");

System.out.println(writer.getEncoding()); // UTF8

writer.close();
```
