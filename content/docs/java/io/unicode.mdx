## Unicode

**Unicode 是字符集（字符的集合与编号），而 UTF-8 和 UTF-16 是该字符集的编码实现（字符在计算机内存或文件中具体的二进制存储方式）。**

简单来说：**Unicode 负责给世界上每一个字符分配一个唯一的“编号”（码点），编码实现负责把这个编号转换成具体的“字节序列”。**

如果直接用固定长度（如 4 字节）去存储每个 Unicode 码点，会造成极大的空间浪费（例如纯英文文本会膨胀 4 倍）。因此需要编码格式来规范“如何高效地用二进制存储码点”。

## UTF-8

可变长编码：1 ~ 4 字节

UTF-8 是目前互联网上使用最广泛的编码（占比超 98%）。

**编码规则：**

- **ASCII 字符（英文字母、数字、基础符号）：** 占用 **1 字节**，完全兼容 ASCII 码。

- **欧洲文字/拉丁字母变体：** 占用 **2 字节**。

- **常用中日韩文字：** 占用 **3 字节**。

- **生僻字、Emoji 等：** 占用 **4 字节**。

## UTF-16

可变长编码：2 或 4 字节

**编码规则：**

- **基本多语言平面字符（绝大多数常用汉字、英文等）：** 占用 **2 字节**。

- **辅助平面字符（生僻字、Emoji 等）：**占用 **4 字节**。

- **优点：**

  - **处理常用汉字效率更高：** 绝大多数常用中文在 UTF-16 下只占 2 字节（而在 UTF-8 下占 3 字节）。

  - 很多现代语言/系统的**内部内存表示**（如 Java、JavaScript、Windows API、.NET）都采用 UTF-16 或类似结构。

- **缺点：**

  - 处理英文文本时尺寸比 UTF-8 大一倍。

  - 存在字节序问题。

## 汇总

| **特性**         | **Unicode**              | **UTF-8**                 | **UTF-16**            |
| ---------------- | ------------------------ | ------------------------- | --------------------- |
| **字节长度**     | 抽象概念，不涉及物理字节 | 1、2、3、4 字节（可变长） | 2 或 4 字节（可变长） |
| **英文占用**     | -                        | 1 字节                    | 2 字节                |
| **常用中文占用** | -                        | 3 字节                    | 2 字节                |
