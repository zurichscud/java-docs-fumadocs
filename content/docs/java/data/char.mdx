---
title: "char"
---

在 Java 中，`char` 是用于存储单个字符的基本数据类型



- 存储空间：** **占用 16 位（2 字节）** 的无符号整数。

- **编码标准**：基于 **UTF-16** 编码，本质上存储的是 Unicode 字符集对应的数值。

- **数值范围**：无符号整数，范围为 `0` 到 `65,535`（即 `'\u0000'` 到 `'\uffff'`）。

```java
// 1. 使用单引号字面量
char c1 = 'A';
char c2 = '中';

// 2. 使用 Unicode 转义字符
char c3 = '\u0041'; // 对应字符 'A'

// 3. 直接赋值整数 (0 - 65535)
char c4 = 65; // 对应字符 'A'

// 4. 转义字符
char c5 = '\n'; // 换行符
```

由于 `char` 本质上是一个无符号 16 位整数，它可以与数字类型互相转换：

```java
char c = 'A'; // ASCII/Unicode 值为 65
int code = c + 1; // 结果为 66
char nextChar = (char) (c + 1); // 强制转换后得到 'B'
```
