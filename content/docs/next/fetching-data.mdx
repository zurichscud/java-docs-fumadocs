数据获取的核心哲学是：**优先推荐在服务端（Server Components）获取数据**，并结合 **流式传输（Streaming）** 与 React Suspense 来优化加载体验。

## 服务端组件获取数据

Next.js 推荐尽可能在服务端组件（`async Component`）中直接请求数据，主要有两种方式：

### 使用原生 fetch API

可以直接在异步组件中使用 `await fetch(...)`。

```tsx
export default async function Page() {
  const data = await fetch('https://api.vercel.app/blog')
  const posts = await data.json()
  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  )
}
```

### 使用 ORM 或数据库直接查询

因为服务端组件运行在服务端，你的数据库凭据和查询逻辑**完全不会泄漏到客户端 Bundle 中**。

```tsx
import { db, posts } from '@/lib/db'

export default async function Page() {
  const allPosts = await db.select().from(posts)
  return (
    <ul>
      {allPosts.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  )
}
```

## 客户端组件获取数据

当必须在客户端组件（`'use client'`）处理数据时，主要有以下途径：

服务端**发起请求但不 `await`**，将 Promise 传给客户端组件，客户端组件通过 React 的 `use()` hook 读取该 Promise：

- **服务端组件 (`app/blog/page.tsx`)**：

  ```tsx
  import Posts from '@/app/ui/posts'
  import { Suspense } from 'react'
  
  export default function Page() {
    const postsPromise = getPosts() // 注意：这里不 await
    return (
      <Suspense fallback={<div>Loading...</div>}>
        <Posts posts={postsPromise} />
      </Suspense>
    )
  }
  ```

- **客户端组件 (`app/ui/posts.tsx`)**：

  ```tsx
  'use client'
  import { use } from 'react'
  
  export default function Posts({ posts }: { posts: Promise<any[]> }) {
    const allPosts = use(posts) // 读取服务端传来的 Promise
    return (
      <ul>
        {allPosts.map((post) => <li key={post.id}>{post.title}</li>)}
      </ul>
    )
  }
  ```
