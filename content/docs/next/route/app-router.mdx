在 Next.js 中，app 目录下的每个文件夹都代表一个路由段（route segment），并直接映射到 URL 路径。无需配置路由表，框架会根据您的文件结构自动处理。

## 项目结构

```
src/
└── app
    ├── page.tsx -> / 首页
    ├── layout.tsx -> 布局组件
    ├── template.tsx -> 模板组件
    ├── loading.tsx -> 加载组件
    ├── error.tsx -> 错误组件
    └── not-found.tsx -> 404组件
    ├── xiaoman
    │   └── page.tsx -> /xiaoman 小满页面
    └── daman
        └── page.tsx -> /daman 大满页面
```

## page

在 **Next.js App Router** 中，`page.tsx` **默认是服务端组件**，但你可以通过添加 `"use client"` 把它变成客户端组件。

## layout

Layout 是一个接收 `children` React Node 的默认导出组件：

### 根布局

 `app/layout.tsx`必需文件，所有页面共享，必须包含 `<html>` 和 `<body>` 标签：

```jsx title=" app/layout.tsx"
export const metadata = {
  title: '我的网站',
  description: '网站描述',
}

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="zh-CN">
      <body>
        <header>全局导航</header>
        {children}
        <footer>全局页脚</footer>
      </body>
    </html>
  )
}
```

### 嵌套布局

在子目录中添加 `layout.tsx`,会嵌套在父布局内部：

```
app/
├── layout.tsx        ← 根布局
├── dashboard/
│   ├── layout.tsx    ← dashboard 专用布局
│   ├── page.tsx
│   └── settings/
│       └── page.tsx  ← 同时被两个布局包裹
```

```tsx
// app/dashboard/layout.tsx
export default function DashboardLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <div className="flex">
      <aside>侧边栏</aside>
      <main>{children}</main>
    </div>
  )
}
```

渲染时的组件嵌套关系为：

`<RootLayout>` $\rightarrow$ `<DashboardLayout>` $\rightarrow$ `<DashboardPage>`

### 多个根布局

例如：

- `/` 首页使用一种布局

- `/products` 商品页使用另一种布局

使用Route Groups用括号命名的文件夹，不影响 URL,可用于让不同页面组有完全不同的布局：

```
app/
├── (home)/
│   ├── layout.tsx    ← 首页页面布局
│   └── page.tsx      → /
├── (shop)/
│   ├── layout.tsx    ← 商店布局
│   └── products/
│       └── page.tsx  → /products
```

<Callout title="注意" type="warning">

多个根布局时需要删掉顶层的 `app/layout.tsx`,每个 group 的`layout.tsx`里写完整的 `<html>`。

</Callout>

## loading

Next.js的loading是借助了`Suspense`实现的

```jsx
export default function Loading() {
    return (
        <div>
            <h1>Loading...</h1>
        </div>
    )
}
```

## error

Next.js的error是借助了`Error Boundary`实现的。

```tsx title="error.tsx"
'use client' //错误组件必须是客户端组件
export default function Error() {
    return (
        <div>
            <h1>Error</h1>
        </div>
    )
}
```
