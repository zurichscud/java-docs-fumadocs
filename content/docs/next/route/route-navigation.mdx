## Link

参考文档  [Link](/docs/next/components/link)

```jsx
import Link from 'next/link'

export default function Home() {
  return (
    <nav>
      <Link href="/about">关于我们</Link>
      <Link href="/blog/hello-world">文章</Link>
    </nav>
  )
}
```

如果需要使用onClick，请在客户端组件中使用

## useRouter

获取路由器router

```jsx
'use client'
//因为需要使用DOM，因此只能在客户端组件中
import { useRouter } from "next/navigation"
export default function Page() {
    const router = useRouter()
    return (
        <>
        <button onClick={() => router.push("/page")}>跳转page页面</button>
        <button onClick={() => router.replace("/page")}>替换当前页面</button>
        <button onClick={() => router.back()}>返回上一页</button>
        <button onClick={() => router.forward()}>跳转下一页</button>
        <button onClick={() => router.refresh()}>刷新当前页面</button>
        <button onClick={() => router.prefetch("/about")}>预获取about页面</button>
        </>
    )
}
```



## 重定向

唯一区别是返回的 HTTP 状态码。

| 函数                  | 状态码  | 语义     | 浏览器/SEO 行为                                    |
| --------------------- | ------- | -------- | -------------------------------------------------- |
| `redirect()`          | **307** | 临时跳转 | 不缓存。搜索引擎继续索引原 URL                     |
| `permanentRedirect()` | **308** | 永久跳转 | 被浏览器**永久缓存**。搜索引擎会把权重转移到新 URL |

**浏览器缓存重定向**：浏览器会把这个“旧地址 → 新地址”的对应关系记在本地缓存里，之后再遇到旧地址，直接在本地跳转，根本不发请求给服务器。

### redirect

临时重定向

> 暂时跳转到另一个地址

```jsx
import { redirect } from "next/navigation"
export default async function Page() {
   const checkLogin = await checkLogin()
   //如果用户未登录，则跳转到登录页面
   if (!checkLogin) {
    redirect("/login")
   }
   return (
    <div>
        <h1>Page</h1>
    </div>
   )
}
```



### permanentRedirect

永久重定向

> 这个 URL 永久不存在了，以后都应该使用新地址。

```jsx
//用法跟redirect一样，只是状态码不同
import { permanentRedirect } from "next/navigation"
export default async function Page() {
   const checkLogin = await checkLogin()
   if (!checkLogin) {
    permanentRedirect("/login")
   }
}
```
