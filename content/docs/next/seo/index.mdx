SEO(Search Engine Optimization)，即搜索引擎优化，是一种通过优化网站结构和内容，提高网站在搜索引擎中的排名，从而吸引更多流量和用户的策略。

>  SEO是一个长期优化过程(一般优化1-3个月才能看到效果)，无需急于求成。

## SEO实践

2. robots.txt 和 sitemap.xml 的配置
3. TDK优化 + HTML语义化标签
4. JSON-LD
5. Open Graph
6. Web Vitals

## 让网站收录

新网站上线后，搜索引擎不会立刻自动发现它。想要快速、稳定地被 Google、百度等搜索引擎收录，需要完成从**技术准备、主动提交到内容引流**的一整套流程。

### 1.基础技术搭建

- 检查 `robots.txt` 文件

- 准备站点地图（Sitemap.xml）

- 确保服务端正确渲染 TDK

### 2.主动提交到官方站长平台

主动将网站“报备”给搜索引擎，是缩短收录时间最有效的方法。

<Callout title="一定要提交到站长平台吗" type="warning">

提交到站长平台（如 Google Search Console、百度搜索资源平台）**并不是强制性的**。即使你什么都不提交，搜索引擎最终也能找到并收录你的网站。但是站长平台可以查看收录结果以及流量。

</Callout>
