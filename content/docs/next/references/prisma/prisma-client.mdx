## Prerequisites

In order to set up Prisma Client, you need a [Prisma schema file](https://docs.prisma.io/docs/orm/v6/prisma-schema/overview) with your database connection, the Prisma Client generator, and at least one model:

```prisma title="schema.prisma"
datasource db {
  provider = "postgresql"
}

generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
}

model User {
  id        Int      @id @default(autoincrement())
  createdAt DateTime @default(now())
  email     String   @unique
  name      String?
}
```

你可以使用命令自动生成：

```sh
pnpm prisma init
```

## Generate Client API

Prisma Client 是基于 Prisma Schema 中定义的模型生成的。为了获得正确的 TypeScript 类型支持，你需要先生成客户端代码：

```sh
pnpm prisma generate
```


该命令会根据你在 Prisma Schema 中配置的 `output` 路径，创建一个 `generated` 目录。

之后都应该从这个生成出来的 Client API 中进行导入。

<Accordions type="single">
  <Accordion title="为什么不使用pnpm dlx prisma generate ？">



因此建议使用项目中的 Prisma CLI 来生成 Prisma Client，这样可以确保生成的代码与项目中安装的 Prisma 版本一致。

  </Accordion>
</Accordions>

## Import Prisma Client

```sh
import { PrismaClient } from "./generated/prisma";

const prisma = new PrismaClient();
// use `prisma` in your application to read and write data in your DB
```

## Use

```js
// run inside `async` function
const newUser = await prisma.user.create({
  data: {
    name: "Alice",
    email: "alice@prisma.io",
  },
});

const users = await prisma.user.findMany();
```

<Callout title="注意" >

所有Prisma Client 的方法返回 Promise 类型

</Callout>
