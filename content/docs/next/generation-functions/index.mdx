---
title: "生成类函数"
---

Generation Functions是 Next.js 提供的**特殊导出函数**，用于让框架在**构建阶段**或**请求阶段**自动调用。

## 特点

- **必须导出（export）**

- **只能写在 `page.tsx` 或 `layout.tsx`**（由于page.tsx会在layout.tsx的children中渲染，因此两者都可以写路由段配置函数）

- **名字固定，Next.js 会自动识别**

- **不是你手动调用，而是 Next.js 调用**

## 执行时机

| 函数                        | 作用         | 静态页面 | 动态页面 |
| --------------------------- | ------------ | -------- | -------- |
| generateStaticParams        | 生成动态路径 | build    | 不执行   |
| generateMetadata            | 生成SEO head | build    | 请求     |
| generateViewport            | 生成viewport | build    | 请求     |
| sitemap                     | 生成站点地图 | build    | 请求     |
| robots.ts                   | 生成爬虫规则 | build    | 请求     |
| page.tsx Server Component   | 生成页面     | build    | 请求     |
| layout.tsx Server Component | 生成布局     | build    | 请求     |
| route.ts GET/POST           | API接口      | 不执行   | 请求     |

```
                    next build
                       |
        --------------------------------
        |                              |
 可提前确定的数据                  无法提前确定的数据
        |                              |
        ↓                              ↓
     SSG生成                       SSR生成
        |                              |
HTML/Metadata/Sitemap          用户请求时计算
```
