---
title: "生成类函数"
---

Generation Functions是 Next.js 提供的**特殊导出函数**，用于让框架在**构建阶段**或**请求阶段**自动调用。

## 特点

- **必须导出（export）**

- **只能写在服务端组件中使用**：它们是 Next.js 在**构建期或服务端渲染（SSR）期**用来处理页面骨架、Head 标签和路由生成的，因此**不能**在客户端组件使用。

- **名字固定，Next.js 会自动识别**

- **不是你手动调用，而是 Next.js 调用**

## 执行时机

生成类函数的执行时机，**完全取决于整个路由是属于“静态渲染SSG”还是“动态渲染SSR”**。

```
                    next build
                       |
        --------------------------------
        |                              |
 可提前确定的数据                  无法提前确定的数据
        |                              |
        ↓                              ↓
     SSG生成                       SSR生成
        |                              |
HTML/Metadata/Sitemap          用户请求时计算
```

`generateStaticParams`比较特别，使用他说明采用SSG，因此只会在build过程调用。
