---

## 基本用法

`generateStaticParams` 的主要作用是结合 **SSG（静态站点生成）**，提前将带有动态路由（如 `[id]` 或 `[slug]`）的页面渲染为纯 HTML 文件，从而极大提升页面的加载速度和 SEO 性能。

- **不使用 `generateStaticParams`**（默认）：默认情况下，该页面会在用户访问时进行 **SSR** 或按需生成（服务端压力大）。

- **使用 `generateStaticParams`**：告知 Next.js 哪些参数需要预先打包。Next.js 会在编译构建时为这些参数中的每一个路径直接预渲染并生成 HTML 静态页面。

`generateStaticParams` 的返回值是一个 **数组**，数组中的每一项是一个**对象**，对象的字段名必须对应动态路由参数名。

对于`/products/[...id]`：

```json
[
 {id:"1"},
 {id:"2"},
 {id:"3"}
]
```

最终会生成：

```
/products/1
/products/2
/products/3
```

## 执行时机

在 Next.js 构建阶段（build ）时执行，而不是用户访问页面时执行。

## 适用场景

- 博客文章列表/详情页（`/posts/1`、`/posts/2`）

- 电商产品详情页（`/products/iphone-15`）

- 帮助中心或文档目录页

## Example

```ts title="app/posts/[id]/page.ts"
// 1. 定义 generateStaticParams
export async function generateStaticParams() {
  // 可以从数据库或 API 获取数据
  const posts = await fetch('https://api.example.com/posts').then((res) => res.json());

  // 返回一个数组，其中每个对象对应动态路由参数 [id]
  return posts.map((post) => ({
    id: String(post.id), // 注意：参数值必须是字符串
  }));
}

// 2. 页面组件
export default async function PostPage({ params }) {
  const { id } = await params;
  
  return (
    <article>
      <h1>文章 ID: {id}</h1>
    </article>
  );
}
```
